
# Autonomous AI Mobile App Builder

A product-first AI builder for creating Android apps with a clear value proposition, commercial strategy, and launch readiness.

## Overview

This repository defines a workflow for an AI coding agent that can take an app opportunity from concept to launch. It is designed for product discovery, implementation, AI integration, monetization, Android packaging, CI/CD, QA, and Play Store preparation.

## What it does

The agent acts as a senior:
- mobile engineer
- React developer
- Android / Capacitor release engineer
- AI product designer
- monetization strategist
- UX designer
- GitHub Actions engineer
- launch engineer

## Product criteria

The skill prioritizes:
- recurring pain points
- high-value AI workflows
- clear monetization paths
- narrow MVPs
- strong retention potential
- Android-first product fit

It avoids generic chatbots, novelty wrappers, and over-engineered apps.

## Stack

- React + TypeScript
